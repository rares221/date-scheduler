# Ieși cu mine? 💛

O pagină personală care o invită pe soția mea la o întâlnire: press play, scroll, „Da”, alege activitatea, ziua și ora, iar la final strofa noastră se scrie singură și ajunge în calendar.

## Personalizare
Totul se schimbă din obiectul `CONFIG`, de la începutul scriptului din `index.html`: melodii, texte, activități, versuri, ore și semnătură.

## Publicare
Settings → Pages → *Deploy from a branch* → `main` / root.

Pentru Claude Code: vezi `CLAUDE.md`.
